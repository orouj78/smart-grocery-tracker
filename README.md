# 🛒 Smart Grocery Tracker (Bilingual Edition)

A powerful command-line application written in Python to manage grocery shopping lists. It features **intelligent unit detection**, **automatic cost calculation**, and full support for both **Persian (Farsi)** and **English**.

## ✨ Key Features

- **Auto-Detection**: Recognizes common items (Milk, Flour, etc.) and assigns the correct standard unit (kg, g, L, ml, pcs).
- **Smart Conversion**: Calculates prices correctly even if you buy small quantities (e.g., buying 500g of flour priced per kg).
- **Bilingual Support**: Users can switch between Persian and English at startup. All UI texts and receipts adapt dynamically.
- **Interactive CLI**: User-friendly menu system for adding items, viewing receipts, and clearing carts.
- **Robust Error Handling**: Prevents crashes due to invalid inputs.
